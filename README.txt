五十音练习 1.1.0

启动方法：双击 GojuonKanaTrainer.exe，或双击“启动五十音练习.bat”。

运行要求：Windows x64，安装 .NET 8 Windows Desktop Runtime（或更新版本）。本成品不需要安装 Python，也不需要联网。

功能：
  · 首页可选择三选一或罗马音填空模式
  · 展开“练习范围”后，可勾选片假名、浊音／半浊音、拗音、小写／促音组合和长音组合
  · 片假名开启后，扩展类别中对应的片假名也会加入题库
  · 答对标绿并自动进入下一题；答错标红并继续作答
  · 自动记录错题和错误罗马音，可在“常错五十音”页面查看

错题与练习范围保存在当前用户的：
  %APPDATA%\GojuonKanaTrainer\mistakes.json

源码位于项目根目录。
